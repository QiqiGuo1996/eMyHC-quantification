# Third-party notices

`fiber-quant.html` loads the following open-source libraries from public content delivery networks at run time. They are used only to read TIFF files. Both are loaded with Subresource Integrity hashes, so the browser refuses any file that differs from the listed version.

| Library | Version | Source | License |
| --- | --- | --- | --- |
| UTIF.js | 3.1.0 | https://github.com/photopea/UTIF.js | MIT, Copyright (c) 2017 Photopea |
| pako | 1.0.11 | https://github.com/nodeca/pako | MIT and Zlib, Copyright (C) 2014–2017 Vitaly Puzrin and Andrei Tuputcyn |

The interface uses the IBM Plex Sans typeface from Google Fonts (SIL Open Font License 1.1) when available, with system fonts as fallback.

The full license texts are available at the source repositories listed above.
