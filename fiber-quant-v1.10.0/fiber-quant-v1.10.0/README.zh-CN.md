# FiberQuant：基于浏览器的肌肉损伤与再生定量工具

[English](README.md) | 中文

FiberQuant 根据麦胚凝集素（WGA）染色分割骨骼肌纤维，识别中央核纤维（CNF）以界定损伤区，并测量阳性标记（如胚胎型肌球蛋白重链 eMyHC）在损伤区内所占的面积比例。

本工具是一个独立的 HTML 文件，可在任何现代浏览器中运行，无需安装。图像只在本机处理，不会上传。

## 快速开始

1. 下载 `fiber-quant.html`，用 Chrome、Edge、Firefox 或 Safari（2023 年及以后的版本）打开。
2. 点"用示例图试一试"熟悉流程，或载入自己的图像。
3. 指定 WGA、DAPI 和阳性标记所在的通道，填写原图像素尺寸（µm/像素）。
4. 点"运行分析"，检查叠加图，校正判错的纤维，导出 CSV。

首次读取 TIFF 需要联网，因为 TIFF 解码组件从公共 CDN 加载。PNG 和 JPG 可以完全离线分析。

## 输入要求

- 经 WGA（纤维轮廓）、DAPI（细胞核）和一种目标标记染色的横切冰冻切片。
- RGB 合成图（PNG、JPG 或 TIFF），或每页一个通道的多通道 TIFF（8 位、16 位或 32 位浮点），例如 Fiji/ImageJ 保存的文件。
- 浏览器无法读取 BigTIFF（通常超过 4 GB）。请先在 Fiji 中用 *Image › Scale* 缩小，再另存为普通 TIFF。
- 超大图像会自动缩小到约 2000 万像素以内再处理。实际处理分辨率显示在界面上，并记录在导出的 CSV 中。

Keyence BZ-X 拼接图：保存时软件可能按拼接视野数不同程度地缩小图像，因此即使拍摄设置相同，不同图像的像素尺寸也可能不同。FiberQuant 会自动从 Keyence TIFF 元数据读取校准值并填入像素尺寸；经其他软件另存的文件通常会丢失这些元数据，此时需手动填写。如需让一批图在相同分辨率下分析，可将"处理时缩小倍数"设为"统一分辨率"：每张图按自己的像素尺寸缩放到统一处理分辨率，使膜加粗等以像素为单位的参数在每张图上含义一致。

## 分析流程

**1. 强度归一化。** 16 位和浮点图像的每个通道，按其第 0.05 和第 99.95 百分位强度线性缩放为 8 位。8 位图像保持不变。

**2. 纤维分割。** 对 WGA 通道扣除背景（局部最小值图经平滑和双线性插值），做高斯平滑（以三次盒式滤波近似），再按阈值分割（默认 Otsu 法¹）。膜掩膜经膨胀以分开相邻纤维。膜以外的连通区域（4 连通）标记为纤维，再向膨胀带内生长以恢复原轮廓，并填补纤维内部被包围的空洞（如细胞核周围）。再以较小的膜加粗（默认 1 像素）分割第二遍，补回被第一遍腐蚀掉的小纤维：只有与已有纤维重叠不足 10% 的区域才会加入，且同样经过各项筛选。以下区域被剔除：面积不在设定范围内、接触图像边缘、最大内切半径低于下限（纤维之间的窄缝）、凸度（面积 ÷ 凸包面积）低于下限（被圆形纤维夹住的内凹缝隙和间质）、形状指数（面积 ÷ 最大内切圆面积）超过上限，或细胞核占比超过上限（标记阳性占一半以上的区域不按细胞核占比剔除，以保护含中央核的小再生纤维）。后两项用于剔除会被误当成纤维的间质。

**3. 细胞核与标记掩膜。** DAPI 和标记通道以同样方式扣除背景、平滑（σ = 1 像素）并阈值分割。

**4. 中央核纤维。** 在每根纤维内计算倒角（3–4）距离变换²。距边界超过"中心区内缩距离"的像素构成中心区；小纤维的内缩距离以最大内切距离的 40% 为上限。中心区内细胞核面积达到设定值的纤维判为中央核纤维，从而排除膜下的正常边缘核。

**5. 标记阳性纤维。** 标记覆盖面积达到设定比例的纤维判为阳性；可选择把纤维轮廓向外扩一段距离后再计算（适用于标记集中在纤维外缘的情况）。WGA 分割漏掉的小阳性纤维会被自动补充：以阳性像素中再做一次 Otsu 得到的阈值提取标记阳性物体，并闭合约 1.5 µm 以内的环形缺口；不与已识别纤维相连、面积在设定范围内、内切半径≥2.5 µm、形状指数≤3、且落在 WGA 膜上的部分不超过 70%的物体被补充为纤维。

**6. 损伤区。** 损伤区为所有中央核纤维的并集，可选择同时纳入标记阳性纤维。没有纤维的细胞核密集浸润区可以手动圈画，或按局部细胞核覆盖率自动识别后加入。未识别为纤维的区域也可计入损伤区：可按类别选择（因形状或细胞核占比被剔除的间质、过大区域、过小碎片、接触图像边缘的区域），也可单击单个区域计入或取消。与切片外背景相连的区域不会计入。这些区域只计入不属于任何纤维的像素，其中的纤维仍按各自判定。

**7. 主要结果。** 损伤区内标记阳性面积比例：

```
标记阳性比例 (%) = (损伤纤维内标记阳性面积 + 无纤维损伤区内标记阳性面积)
                   / (损伤纤维面积 + 无纤维损伤区面积) × 100
```

标记阳性面积可按阳性像素计算（默认），或按阳性纤维的整根面积计算。

## 手动校正

单击任意纤维或表格中的一行，可查看该纤维的数据，并用按钮或快捷键校正：

| 操作 | 快捷键 | 作用 |
| --- | --- | --- |
| 切换中央核 | C | 改变中央核判定，从而改变是否属于损伤区 |
| 切换标记阳性 | R | 标为阳性按整根面积计入，标为阴性计为 0 |
| 排除或恢复纤维 | X | 从所有统计中移除，例如粘连纤维或伪影 |
| 恢复自动判定 | 按钮 | 清除该纤维的全部手动判定 |

未被识别为纤维的区域显示为灰色（"未识别区域"）。单击可查看原因，并将其设为"损伤区""非损伤区"或"按类别"；如果它其实是一根纤维，可"转为纤维"（快捷键 I、N、F）。原因包括：小于面积下限、大于面积上限（通常是膜有缺口导致几根纤维连在一起）、形状不规则、细胞核占比过高、接触图像边缘，或与切片外的背景连通。把"膜加粗"调到约 4 µm 对应的像素数或调低 WGA 阈值，通常能找回膜不完整的纤维。

三种圈画工具可补充自动分析漏掉的内容：

| 工具 | 作用 |
| --- | --- |
| **框选损伤区** | 圈内不属于纤维的像素计入损伤区 |
| **圈画纤维** | 圈内尚未属于其他纤维的像素组成一根新纤维，按同样规则判定，也可像其他纤维一样校正 |
| **圈画红色阳性** | 圈内像素计为标记阳性 |

圈画漏掉的纤维时请沿纤维内缘，避免把膜圈进去。"撤销"按圈画顺序逐个删除，"清除"删除全部；重新运行分析时会自动重新应用所有圈画。所有手动校正和圈画都记录在 CSV 中。

## 输出

**界面汇总：** 损伤区内标记阳性比例；纤维数；中央核纤维数及比例；损伤区面积（单列无纤维部分）；标记阳性面积；损伤区内标记阳性纤维数及比例；损伤纤维占全部纤维面积的比例；损伤纤维、非损伤纤维和标记阳性损伤纤维的面积均值 ± SD 与中位数。

**CSV 导出**（UTF-8 带 BOM，可直接用 Excel 打开），分四部分：

1. 汇总结果。
2. 纤维面积统计（n、均值、标准差、中位数），分损伤纤维、非损伤纤维、标记阳性损伤纤维和全部纤维。
3. 参数，包括工具版本、分析时间、图像名称、实际使用的阈值和手动校正数量。
4. 每根纤维一行：编号；面积；中心区面积；中心区核面积；标记占比；计入的标记阳性面积；自动和最终的中央核判定；自动和最终的标记判定；是否属于损伤区；手动校正标记；是否手动圈画；是否由标记补充识别；是否排除；质心坐标。

**PNG 导出：** 当前叠加图（含显示中的纤维编号），用于留档。

面积单位为 µm²，质心坐标为处理分辨率下的像素。

## 验证

用于研究前，应先将自动结果与人工定量比较。建议由两名不知分组的评估者在随机抽取的切片上人工计数中央核纤维和标记阳性纤维并勾画损伤区，以组内相关系数和 Bland–Altman 图报告一致性。本研究的验证结果见论文 [补充图 x]。

## 局限性

- 分割依赖连续的 WGA 膜染色。膜断裂、组织折叠或间质染色过强会导致纤维粘连或被错误分开，需要校正或排除。
- WGA 环不完整的纤维会与间质或背景连通而无法识别。请查看"未识别区域"叠加层，调整膜加粗或 WGA 阈值。
- 没有膜的大片浸润区，如果面积落在纤维面积范围内，可能被分割成一根"巨大纤维"。请将其排除，再作为无纤维损伤区圈画。
- 标记阈值对结果影响很大。在一张测试图中，损伤区标记阳性比例在自动阈值（26）下为 25.9%，阈值 40 时为 11.3%，60 时为 3.8%。请为整个实验设定一个固定阈值，以只加二抗的对照基本为阴性为准。
- Otsu 阈值逐张计算。标记信号稀疏时，自动阈值可能偏低，请打开"红色阳性像素"叠加层核对，必要时改用固定阈值。
- 每次分析一张图像。
